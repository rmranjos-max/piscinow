# Fontes hospedadas

Hospedadas no proprio sistema para nao enviar o IP dos visitantes a servicos de terceiros.
Ambas sao distribuidas sob a SIL Open Font License 1.1 (https://openfontlicense.org), que permite o uso
e a redistribuicao junto com o software.

| Arquivo | Fonte | Direitos | Origem |
|---|---|---|---|
| `manrope-latin-wght.woff2` | Manrope (variavel, pesos 200 a 800, subconjunto latino) | Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope) | pacote `@fontsource-variable/manrope` 5.x |
| `dm-sans-latin-wght.woff2` | DM Sans (variavel, pesos 100 a 1000, subconjunto latino) | Copyright 2014 The DM Sans Project Authors (https://github.com/googlefonts/dm-fonts) | pacote `@fontsource-variable/dm-sans` 5.x |

O subconjunto latino cobre todos os caracteres do portugues (acentos, cedilha, til).
